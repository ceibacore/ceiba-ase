Error de Configuración

El módulo ASE no ha sido configurado correctamente en el entorno anfitrión. Faltan variables de entorno requeridas para la conexión a la base de datos o claves de seguridad.

Por favor, asegúrate de definir las siguientes variables en tu archivo .env:

DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=tu_base_de_datos
DB_USERNAME=root
DB_PASSWORD=
ASE_SECRET_KEY=tu_clave_secreta_hmac
